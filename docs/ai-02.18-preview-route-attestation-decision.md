# AI-02.18 — staging preview-route attestation

## Decision

AI-02.17 is closed and consumed after its sole staging source invocation
returned a deliberately redacted HTTP 404. That result did not distinguish a
missing function route from a rejected token or an unexpected preview context,
and it must not be retried.

AI-02.18 selects the smallest independent prerequisite for any future
replacement decision: prove that one temporary branch-preview function is
published at one explicit path and sees its branch-scoped secret. The function
returns one fixed receipt and has no application, database, provider,
market-data, scan, source, outcome, evaluator, runtime, broker, deployment or
production capability.

## Fixed receipt and containment

The handler is reachable only at
`/api/diagnostics/ai02-preview-route-attestation`. It accepts exactly one
`POST` with the `x-ai02-preview-attestation-token` header, a constant-time
match against `AI02_PREVIEW_ATTESTATION_TOKEN`, Netlify `deploy-preview`
context and the expected site name. It returns only:

```json
{
  "environment": "staging",
  "operation": "ai02_preview_route_attestation",
  "result": "preview_route_attested",
  "credential_values": "not_returned",
  "database_activity": "not_performed",
  "provider_data_access": "not_performed",
  "application_runtime_binding": "not_performed"
}
```

Wrong method, token, context, site name or an absent branch secret returns the
same `{ "error": "not_found" }` response. The function has no `fetch`,
Supabase, environment alias, application-route, scanner, recommendation,
market-data, evaluator or broker dependency.

## Explicit non-successor rule

AI-02.18 is not a retry of AI-02.17 and it cannot call the AI-02.17 function,
the canonical scan route, a provider or staging. A successful receipt is only
evidence that a future replacement decision can safely distinguish preview
transport from a later application prerequisite. It does not create authority
for a source snapshot, outcome evaluation, v2 evidence, cohort, offline
evaluation, promotion, runtime, deployment, broker or production work.
