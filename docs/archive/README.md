# Historical evidence

Files in this directory preserve previous implementation contracts for audit and
regression checks. They are not active product governance, current instructions,
implementation selection or permission to operate a broker. Current execution is
specified in [Ture Execution Engine](../ture-execution-engine.md).

The execution contract dated 2026-10-07 is the byte-preserved predecessor from
main `85764d1fc6993496cefd985d76ac3ace21b8d799`. Existing regression checks for that
implementation read this archived evidence; their assertions remain unchanged.
