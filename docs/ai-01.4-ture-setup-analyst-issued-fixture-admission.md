# AI-01.4 — Ture Setup Analyst issued fixture admission

## Product decision

AI-01.4 is a separate provider-free integrity slice for the completed AI-01.1
comparison and AI-01.2/AI-01.3 input hardening. Its bounded outcome is to
ensure that the comparator counts only an exact frozen evaluation object
emitted by the local fixture evaluator in the same process, rather than a
manually built object that merely has the same public shape and values.

It strengthens local fixture provenance without treating the resulting local
sample as representative, statistically sufficient, measured against real
outcomes, or eligible for promotion.

## Authorized source-only boundary

The evaluator may retain exact object identity in a private in-memory registry
after it creates a frozen result. The comparator may ask only whether a given
object was issued by that registry before inspecting it. The registry is not
exported, serialized, persisted or represented in the aggregate output; it is
lost with the process and cannot act as a durable receipt or cross-process
trust mechanism.

An exact evaluator result must remain admissible. A frozen, structurally
identical shallow clone with the same authority reference, IDs and nested
objects must fail closed without being counted. The aggregate remains detached,
immutable and `not_admitted`.

## Explicit exclusions

This decision grants no model/provider or context-tool invocation, real outcome
source or sink, database/file/network I/O, environment lookup, persistence,
batch execution, route, queue, UI, runtime binding, deployment, canonical
recommendation/ranking/risk/position change, execution, broker instruction, or
model/policy promotion authority.

The registry establishes no real data catalog, durable provenance, signature,
cross-system deduplication or human review process. Each remains a separately
authorized future decision.

## Evidence required for this slice

- focused tests proving a valid evaluator output remains accepted;
- a focused test rejecting a frozen structural lookalike before it is counted;
- a check that the aggregate remains detached and `not_admitted`; and
- normal Ready CI before any request to merge.
