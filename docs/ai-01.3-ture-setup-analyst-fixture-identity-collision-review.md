# AI-01.3 — Ture Setup Analyst fixture identity-collision review

## Product decision

AI-01.3 is a separate provider-free integrity slice for the completed AI-01.1
comparison and AI-01.2 container hardening. Its bounded outcome is to ensure
that a local multi-fixture aggregate cannot count the same underlying
recommendation or shadow trace twice under different fixture labels.

It makes fixture evidence less forgeable without claiming that the resulting
local sample is representative, statistically sufficient, measured against
real outcomes, or eligible for promotion.

## Authorized source-only boundary

The implementation may retain recommendation and trace identities only long
enough to reject an in-memory aggregate input containing a duplicate. It may
continue to emit only the existing detached scalar aggregate; no identity,
fixture, trace or outcome row may appear in that result.

The local set must retain its existing unique fixture ID requirement and now
also fail closed on duplicate `recommendation_id` or `trace_id`. Reordering a
valid set must preserve the same scalar aggregate while returning fresh,
detached output. A candidate ID alone remains non-unique because the existing
contract does not establish it as a one-observation identity.

## Explicit exclusions

This decision grants no model/provider or context-tool invocation, real outcome
source or sink, database/file/network I/O, environment lookup, persistence,
batch execution, route, queue, UI, runtime binding, deployment, canonical
recommendation/ranking/risk/position change, execution, broker instruction, or
model/policy promotion authority.

The work establishes no real data catalog, cross-system deduplication or human
review process. Each remains a separately authorized future decision.

## Evidence required for this slice

- focused tests rejecting duplicate local recommendation and trace identities;
- a permutation test for scalar-output stability and fresh result detachment;
- a check that identities never appear in the aggregate result; and
- normal Ready CI before any request to merge.
