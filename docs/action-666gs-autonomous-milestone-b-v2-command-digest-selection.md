## Selected outcome and authority

`MILESTONE_B_V2_COMMAND_DIGEST_SELECTION_666GS` selects
`position_version_lineage_v2_writer_canonical_command_digest_builder` for
exactly one following implementation action: `ACTION_666GT`.

The builder may accept only the four frozen scalar fields and return one
lowercase hexadecimal SHA-256 digest. It must reject malformed or extra input,
must not accept price, quantity, position identity, policy, timestamp or
caller-supplied digest material, and must not perform I/O. It is server-only
and remains unbound: it cannot resolve a credential, open a connection, call a
routine, write a position, construct a result decoder or attach to a route/UI.

The selection does not modify workflow semantics, branch protection, Netlify,
the Full-CI suite or the no-deduplication policy. It does not grant provider,
database, writer, runtime, broker or execution authority.
