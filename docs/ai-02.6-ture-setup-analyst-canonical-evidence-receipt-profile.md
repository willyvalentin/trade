# AI-02.6 — Canonical evidence receipt profile

## Purpose

AI-02.6 is a server-only, provider-free and I/O-free profile of the one separately authorized staging receipt recorded by AI-02.5. It accepts only a caller-supplied, frozen minimal readback projection for that exact receipt.

The profile does not query Supabase, read the repository, invoke a writer, create a dataset, evaluate an outcome, invoke a model, bind a route or runtime, or affect deployment, broker or production systems.

## Accepted evidence

The accepted readback is constrained to the single staging `historical_synthetic` receipt's canonical identity and deterministic digest, plus its sample/decision classification, reproducibility, inactive-readiness marker, and absence of a primary outcome and diagnostic horizons. It requires `quality_metrics_eligible=true` only to match the stored fixture contract; that field is not evaluator, dataset or promotion authority.

## Result

The only result is `receipt_profiled_not_admitted`. It records four blocking reasons: the primary outcome is absent, diagnostic horizons are absent, the envelope remains inactive-readiness-only, and a separate evaluator admission is required. The next gate is separately authorized completed-outcome evidence admission.

## Authority boundary

AI-02.6 has no repository, staging, production or other I/O authority. It cannot persist source evidence, form an offline dataset, run an offline evaluation, invoke a model, bind runtime, change recommendation/ranking/risk or position state, or place/cancel/submit broker instructions.
