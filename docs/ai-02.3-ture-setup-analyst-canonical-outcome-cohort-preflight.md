# AI-02.3 — Ture Setup Analyst canonical outcome cohort preflight

## Product decision

AI-02.3 is a provider-free, source-only preparation step for a future offline
evaluation cohort. It validates a caller-supplied, bounded in-memory batch of
already issued AI-02.1/AI-02.2 canonical-outcome projections before any future
reader, dataset, evaluation or promotion boundary is considered.

## Authorized source-only boundary

The preflight accepts only a frozen dense array of projections issued by this
same process. It rejects structural lookalikes, another module instance's
projections, duplicate canonical identities and mixed cohort or horizon
material. It returns only cohort, horizon, count and decision-day range; it
does not return or retain projections, identities, outcomes or confidence.

The result remains `not_admitted` for offline evaluation. It is not a dataset,
repository query, holdout, evaluator, persistence record, cross-process
receipt or promotion decision.

## Explicit exclusions

AI-02.3 performs no repository query, model or context-tool call, network or
file I/O, secret lookup, persistence, route, queue, UI or runtime binding. It
does not form an offline dataset, run an evaluation, change recommendation,
ranking, risk, position, execution eligibility, broker state, model or policy.

An actual staging/read-only cohort query, frozen time-based holdout, measured
evaluation and human promotion review remain separately authorized work.

## Evidence required for this slice

- accepted same-process issued projections yield a fresh frozen, metadata-only
  preflight result;
- lookalikes, foreign issuers, duplicate identities, mixed cohort/horizon,
  mutable or sparse batches and accessor-backed input fail closed; and
- normal Ready Full CI before merge, followed by exact-main verification.
