## Selected outcome and authority

`MILESTONE_B_PRODUCT_OUTCOME_SELECTION_666FZ` selects
`provider_free_exit_decision_explanation_projection` for exactly one following
implementation action: `ACTION_666GA`.

The projection may accept a closed tuple of `decision_status`,
`decision_reason` and `decision_priority`, reject every other shape, and return
stable Swedish advisory copy plus an explicit non-authority classification. It
must not import or invoke the exit evaluator, receive an input JSON document,
receive a price, quantity, position identifier, recommendation identity,
digest, policy, credential or timestamp, read a service, mutate state, make a
network request, render a component, create a route or attach to application
state. It must make no buy/sell/prepare/execute claim.

This is an advisory clarity primitive, not a decision engine. The existing
canonical evaluator stays default-off and runtime-unwired. An eventual caller
must separately re-read durable server state and pass its own later admission;
this action grants none of that authority.

The projection does not import or invoke the exit evaluator. It only explains a
closed, already-declared classification and cannot create, alter or authorize a
decision.
