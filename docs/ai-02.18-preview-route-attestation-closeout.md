# AI-02.18 Preview Route Attestation Closeout

**Status:** closed on 2026-09-08 — the single permitted request was stopped by
an unidentified upstream preview layer before the temporary function could run.

## Purpose and boundary

AI-02.18 was not an evidence-creation, provider, database or application
runtime operation. It existed solely to distinguish an isolated Netlify
deploy-preview transport route from the earlier AI-02.17 fail-closed adapter
result. Its fixed scope was one temporary, POST-only function with no fetch,
database, provider, source, scanner, evaluator, writer, runtime or broker
capability.

The function accepted only a matching one-time token in a deploy-preview for
the `trade-vl` site. Its sole success receipt was fixed metadata declaring that
no credential value, database activity, provider access or application-runtime
binding had occurred. Every method, context, site or token mismatch returned
the same fixed 404 response.

## Verified evidence

- Temporary non-merge PR #409 was built from commit
  `ef89a7d4148f02da0dc92c169a1652e55582996b`.
- Ready Full CI run `34253266199` passed the unchanged six provider-free
  shards, protected aggregate and merge-candidate provenance POC for that
  exact commit.
- Netlify deploy `6aa033fe3ae6e400087d02db` was `ready`, had
  `deploy-preview` context and PR review `409`, named the same branch and
  commit, and exposed the custom POST route.
- A fresh random secret was configured only for that named branch and only for
  function runtime scope. Exactly one POST was made to the custom preview
  route. It returned HTTP `401`.
- A subsequent GET-only project-metadata read reported neither project password
  protection nor team-SSO protection. It did not identify the upstream layer
  that emitted the `401` and did not read a secret or change configuration.

The temporary function's source can return only HTTP `200` or its uniform
HTTP `404`; it has no branch that emits `401`. The observed `401` therefore
establishes only that an upstream layer rejected the request before the
function could issue a receipt. It does not identify the responsible control
and supplies no marker, source, outcome, provider, database or
application-runtime evidence.

## Containment and cleanup

The branch-scoped secret was removed immediately after the one request and an
idempotent removal command then completed successfully. PR #409 was closed
without merge; its remote branch, local branch and isolated worktree were
removed. The temporary route and fixture never reached `main`.

## Consequence

AI-02.18 is closed, not retriable under its one-request budget. It does not
alter AI-02.17's closure and does not admit a canonical cohort, the v2
migration, a source call, provider invocation, persistence, evaluator,
runtime, deployment, broker or production action.

Any future attempt that needs preview transport must be a fresh, separately
authorized decision. It must first identify the upstream preview layer and
provide a narrowly authenticated path through it while preserving branch-only
secret scope and without weakening visitor access globally. That future decision
is independent of other roadmap work.
