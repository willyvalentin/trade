## Selected outcome and authority

`MILESTONE_B_V2_COMMITTED_RESULT_DECODER_SELECTION_666GV` selects
`position_version_lineage_v2_writer_strict_committed_result_decoder` for
exactly one following implementation action: `ACTION_666GW`.

The future decoder may accept only unknown raw result material plus an already
authenticated server-owner value supplied by its future server-only caller. It
must require one own plain record with exactly `disposition`, `position_id`,
`position_version` and `initial_history_identity`; accept only `created` or
`replayed`; require version `1`; require canonical UUID scalar identities; and
require the frozen `position_id:authenticated_server_owner:1` history identity.
It must reject arrays, extra or missing keys, symbols, inherited keys,
accessors, duplicate rows, noncanonical values and legacy snapshot fields. It
must not query, resolve, retry, construct a transport result, call a routine or
write state.

The selection does not modify workflow semantics, branch protection, Netlify,
the Full-CI suite or the no-deduplication policy. It grants no transport,
credential, provider, database, writer, route/UI, runtime, broker or execution
authority.
