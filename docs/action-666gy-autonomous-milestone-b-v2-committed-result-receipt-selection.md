verified the strict V2 committed-result decoder. This decision concerns only an
immutable in-memory receipt projection that can join an already decoded result
to the existing canonical command digest; it does not select storage, a
transport, a private routine invocation or a runtime caller.

## Selected outcome and authority

`MILESTONE_B_V2_COMMITTED_RESULT_RECEIPT_SELECTION_666GY` selects
`position_version_lineage_v2_writer_immutable_committed_result_receipt_projection`
for exactly one following implementation action: `ACTION_666GZ`.

The future projection may accept only an already decoded V2 committed result
and the output of the existing canonical command-digest boundary. It must
revalidate the canonical lowercase digest, preserve only the fixed committed
result scalars and produce a fresh frozen in-memory receipt. It must reject a
caller-supplied digest claim, unknown raw result material, legacy snapshot
fields, mutable nested state, transport responses and any persistence handle.
It must not query, resolve, retry, open a connection, call a routine or write
state.

The selection does not modify workflow semantics, branch protection, Netlify,
the Full-CI suite or the no-deduplication policy. It grants no transport,
credential, provider, database, writer, route/UI, runtime, broker or execution
authority.
