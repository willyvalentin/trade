**Status:** superseded for preview-layer attribution on 2026-09-08; its
non-retry and no-provider conclusions remain in force.

## Bounded objective

Select the next safe decision after the separately consumed AI-02.17 source
operation and AI-02.18 preview-route attestation. This record supplies no

production authority.

## Evidence considered

- AI-02.17's sole authorized source invocation returned HTTP `404` before its
  marker, canonical dispatch, provider request or durable evidence path.
- AI-02.18's sole authorized preview-route request returned HTTP `401` before
  its deliberately minimal function could run. Project metadata rules out
  project password and team SSO.
- Read-only deploy metadata for the exact AI-02.18 preview showed the custom
  function route before the Next catch-all route and reported that Edge
  functions were present. The available read controls did not expose Edge
  function rules or logs.
- The repository contains no project middleware file, Netlify Edge-function
  source, or `netlify.toml` Edge configuration that could explain the `401`.
- A non-secret local-process configuration inventory found the automation,
  provider and Supabase service inputs present but no
  `TURE_APPLICATION_OWNER_USER_ID`. The existing scan route verifies that
  principal before scan dispatch, so this local alternative is blocked before
  any provider request. It did not contact the identity provider or read any
  configuration value.

## Alternatives and decision

| Alternative | Decision | Reason |
| --- | --- | --- |
| Retry AI-02.17 or AI-02.18 | rejected | Both one-shot budgets are consumed; retrying would violate their closeouts. |
| Use the local scan route | rejected | The required server-owned application principal is absent from the local process configuration, so it cannot prove a staging-only operation and must stop before provider use. |
| Add another temporary preview route or relax visitor controls | rejected | It would not identify the upstream rejecting layer and would widen access without evidence. |
| Perform a future read-only Edge/platform attribution | deferred | It is the smallest remaining fact needed for a future preview transport, but requires a separately available, read-only Edge configuration or log view. |

The autonomous governance decision was therefore `redesign_or_stop`. No
transport was started under this decision.

## Later source attribution and supersession

[AI-02.20's closeout](./ai-02.20-proxy-route-attestation-closeout.md) later
established the missing repository-owned fact: `proxy.ts` applies application
session enforcement before dispatch for API paths outside its explicit
allowlist. AI-02.18's temporary path was outside that allowlist, which explains
its HTTP `401` without attributing it to an unidentified Netlify Edge or
platform layer.

AI-02.20 moved its equally temporary, no-provider function under the already
allowlisted `/api/automation/` prefix. Its one permitted request returned only
the function's uniform HTTP `404`, not the fixed success receipt. This rules
out the old *unidentified upstream-layer* blocker, but does not establish a
working credential, function configuration, source, provider, database,
evaluator, runtime or outcome path. No retry is permitted. Consequently this
record is superseded only as an attribution hypothesis; its default-deny,
non-retry and local-owner-principal conclusions remain current.

## Residual risk and containment

The unknown upstream rejection remains a delivery blocker, not evidence that a
function, credential, staging source or provider is working. The local missing
principal is a separate configuration blocker, not permission to discover an
owner by broad user or table access. No secret values, identifiers, row data,
provider payloads or browser requests were retained. No branch deployment,
configuration change, database operation or provider request occurred under
this decision. The older temporary source-adapter Draft PR #397 was closed as
a reversible merge-risk containment step; its remote branch remains preserved
as historical evidence and was not deployed or changed.
