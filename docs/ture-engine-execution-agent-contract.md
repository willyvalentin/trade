# Ture Execution Engine — contract location

The current normative contract is [Ture Execution Engine](./ture-execution-engine.md).
It defines autonomous decisions and IBKR API execution under a versioned user
mandate, with deterministic risk controls and no per-trade user action.

This compatibility link preserves existing references. The previous contract is
retained only as [historical implementation evidence](./archive/ture-engine-execution-agent-contract-2026-10-07.md).
Its old capability restrictions still describe that old implementation, but it
does not govern the future engine. Historical fixtures are not IBKR acceptance
and this documentation change activates no runtime capability.
