# AI-01.1 — Ture Setup Analyst multi-fixture baseline comparison

## Product decision

AI-01.1 is the next separately selected product slice after the completed
AI-00.1–AI-00.6 provider-free contract sequence. Its bounded outcome is a
deterministic, in-memory comparison of multiple already-admitted local fixture
evaluations against the current Ture decision baseline represented by each
fixture's canonical decision.

The slice is selected because it turns the explicit AI-00.6 evidence gap into
a reviewable local contract without reopening any of the deferred Milestone B
runtime gates. It does not assert that any fixture set is statistically
sufficient, that the analyst creates incremental value, or that a model or
policy may be promoted.

## Authorized source-only boundary

The implementation may accept only a frozen, locally supplied collection of
already-admitted AI-00.5 fixture-evaluation records and a scalar baseline
descriptor. It may calculate a small immutable aggregate of decision-agreement
and outcome-direction counts. It must reject mutable, widened, malformed,
duplicate or cross-baseline material.

The comparison must always retain an `evidence_incomplete` status and an
explicit `not_admitted` promotion disposition. A structural minimum of two
fixtures distinguishes this contract from AI-00.5's single-fixture boundary;
it is **not** a sample-size or significance threshold.

## Explicit exclusions

This decision grants no model/provider or context-tool invocation, outcome
source or sink, database access, file access, network I/O, environment lookup,
persistence, batch job, route, queue, UI, runtime binding, deployment,
canonical recommendation/ranking/risk/position change, execution, broker
instruction or model/policy promotion authority.

The input data remains local test/fixture material. A real baseline dataset,
realized-outcome collection, measured statistical evaluation, human promotion
review, runtime binding, or any external service access each requires a later
separate product decision and explicit authorization.

## Evidence required for this slice

- focused provider-free contract tests for a valid detached aggregate;
- default-deny promotion disposition and authority containment;
- rejection of malformed, widened, mutable, duplicate and cross-baseline
  evidence; and
- normal Ready CI before any request to merge.
