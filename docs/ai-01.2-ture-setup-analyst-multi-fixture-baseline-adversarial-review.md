# AI-01.2 — Ture Setup Analyst multi-fixture baseline adversarial review

## Product decision

AI-01.2 is a separate, provider-free review of the completed AI-01.1 local
baseline-comparison contract. Its outcome is to prove that the comparison
accepts only a canonical frozen fixture array and preserves a stable public
failure boundary when hostile in-memory container shapes are supplied.

The review is selected to make the local evidence contract robust before any
later, separately decided dataset or human review. It does not make the local
fixtures representative, measure analyst value, admit promotion, or reopen a
Milestone B runtime gate.

## Authorized source-only boundary

The review may construct frozen local fixture evaluations already admitted by
AI-00.5, call the existing AI-01.1 comparator repeatedly, and test only its
in-memory output or public rejection. It may cover widened and symbol-bearing
arrays, nonstandard prototypes, accessor-backed array entries, holes and
cross-call output detachment. A narrowly scoped source correction is allowed
only where it makes the existing comparator fail closed on that material.

Accepted inputs remain ordinary frozen arrays with only dense own data entries
and the standard `Array.prototype`. Rejected material must surface through the
existing public `TypeError` boundary rather than evaluate an untrusted getter
or preserve untrusted metadata.

## Explicit exclusions

This decision grants no model/provider or context-tool invocation, real outcome
source or sink, database/file/network I/O, environment lookup, persistence,
batch execution, route, queue, UI, runtime binding, deployment, canonical
recommendation/ranking/risk/position change, execution, broker instruction, or
model/policy promotion authority.

No real dataset or statistical conclusion is produced. Those remain separate
product decisions with their own evidence and authority boundaries.

## Evidence required for this slice

- focused adversarial tests for widened, symbol-bearing, nonstandard-prototype,
  sparse and accessor-backed arrays;
- public fail-closed `TypeError` behavior without evaluating hostile getters;
- repeated-call output detachment and default-deny preservation; and
- normal Ready CI before any request to merge.
