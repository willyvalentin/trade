# AI-02.2 — Ture Setup Analyst canonical outcome issuer boundary

## Product decision

AI-02.2 is the bounded, provider-free successor to AI-02.1. It makes an
already redacted canonical-outcome projection distinguishable from a frozen
structural lookalike inside the same server process. A future in-memory
consumer can therefore require that its input was actually emitted by the
AI-02.1 adapter rather than merely matching its public shape.

## Authorized source-only boundary

The AI-02.1 module records each projection it creates in a module-private
`WeakSet` and exposes a predicate for that module instance only. The predicate
adds no fields to the projection and cannot be satisfied by copying,
serializing, deserializing or independently recreating the public DTO. A
projection from another module instance is also rejected.

The output remains `not_admitted` for offline evaluation and all promotion.
The issuer predicate is only in-process provenance hygiene; it is not a
durable receipt, signature, cross-process capability or authority grant.

## Explicit exclusions

AI-02.2 performs no repository query, dataset collection, provider/model or
context-tool invocation, I/O, persistence, secret lookup, route/queue/UI or
runtime binding. It cannot change recommendation, ranking, risk, position,
execution eligibility, broker state, model or policy.

A read-only cohort query, frozen holdout, measured evaluation and human
promotion review remain separate decisions with their own authority and
evidence requirements.

## Evidence required for this slice

- a projection issued by this module instance is recognized;
- a frozen structural lookalike, a cloned projection and another module
  instance's projection are rejected; and
- normal Ready Full CI before merge, followed by exact-main verification.
