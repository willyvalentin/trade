# AI-02.3 — Ture Setup Analyst local outcome cohort admission

AI-02.3 is a fresh, bounded successor selected after the completed AI-02.1
projection and AI-02.2 issuer boundary. It admits a **single already-loaded,
same-process set** of AI-02.2-issued outcome projections only long enough to
produce a small, immutable cohort summary for a future evaluation boundary.

It is deliberately not a reader, dataset builder, evaluator or promotion
mechanism. The admitted value remains `not_admitted` for offline evaluation
and every policy/model promotion.

## Accepted boundary

The caller supplies exactly one frozen object containing one non-empty frozen
array. Every member must:

- be an exact projection issued by this module instance's AI-02.1/AI-02.2
  dependency, rather than a structural lookalike, clone or another module
  instance's output;
- belong to the same declared `sample_type` and `cohort`;
- have a distinct canonical identity; and
- carry one of the closed terminal-outcome literals already enforced by
  AI-02.1.

The returned summary has no canonical identities, symbols, tickers, sectors,
raw provider material, prompts, model output or member payloads. It retains
only the common sample/cohort, count, first/last decision day and terminal
outcome counts. The output and every nested member are fresh and frozen.

Malformed, mutable, widened, accessor-backed, empty, mixed-cohort,
duplicate-identity, cloned or cross-module material fails closed before any
evaluation can be inferred.

## Authority boundary

AI-02.3 is server-only and in-process. It performs no repository or Supabase
query, no data collection, no model/provider/context-tool invocation, no I/O,
no persistence/export, no route/queue/UI binding and no runtime binding. It
cannot create a dataset, admit offline evaluation, promote a model or policy,
change recommendation/ranking/execution/position/risk state, or submit a
broker instruction.

The separately observed empty staging tables remain a real availability
blocker, not an input this module is allowed to repair. A later read-only
cohort source, frozen holdout, measured evaluation and human promotion review
each require their own named authority and evidence gate.

## Verification

`tests/e2e/ai-02.3-ture-setup-analyst-local-outcome-cohort-admission.spec.ts`
verifies the valid detached summary, same-process issuer requirement, duplicate
and mixed-cohort rejection, accessor-safe fail-closed behavior, server-only
static containment and one-time registration in the existing intelligence CI
shard. It changes neither the six-shard topology nor CI policy.
