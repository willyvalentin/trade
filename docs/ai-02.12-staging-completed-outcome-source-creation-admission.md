# AI-02.12 — staging completed-outcome source-creation admission

## Decision

AI-02.11's staging-only aggregate preflight established that the selected
server-owned source has no completed bundle. AI-02.12 makes the only eligible
future design response precise without fabricating a dataset: one server-owned
official snapshot may be evaluated once in staging to create at most one
owner-bound outcome bundle with a primary 60-minute result and the exact
15/30/60-minute diagnostics.

The existing authenticated official scheduled outcome-evaluation path remains
the canonical producer and persistence shape, but its current five-batch,
ten-snapshot default is not admitted for this operation. A future operation
therefore needs a separate, temporary staging-only branch-deploy one-shot
adapter with strict one-batch/one-snapshot limits. It cannot use
caller-supplied snapshots, local storage, fixtures, historical synthetic
evidence or the private legacy-preservation relation.

## Authority boundary

The contract is server-only and I/O-free. A valid plan returns
`source_creation_scope_validated_not_authorized_not_executed`; it does not authorize or execute the planned operation. It does not access staging or production, inspect a secret or source row, invoke the scheduled evaluator or a provider, persist an outcome, apply the v2 migration or write active evidence.

It also excludes dataset formation, evaluation, promotion, runtime,
deployment, broker and production authority. The v1 inactive-readiness
relation remains untouched, and v2 stays unapplied to shared infrastructure.

## Value and next gate

This turns an empty source from an open-ended blocker into one small, auditable
future operation. It prevents a tempting but invalid shortcut—using synthetic
or historical data—while holding provider cost, credential use and writes
behind separate gates.

The next gate is a separately authorized staging-only provider-cost,
credential-identity and one-shot-transport preflight. It must return only
non-secret, minimum facts needed to decide whether one bounded official
evaluation can be run through an isolated branch deployment. It still cannot
invoke the provider, run the evaluator, write an outcome, apply a migration,
write active evidence or affect runtime, broker or production behavior.
