# Action 666GI — Autonomous advisory presentation-key selection

## Bounded objective

Select one smallest safe successor to the completed Action 666GA–666GH
source-only review cap. The selection may prepare a future presentation
boundary, but it must not read data, invoke an evaluator, change a decision or
wire a route, component, API, server action, queue, scheduler or deployment.

## Decision record

| Field | Record |
| --- | --- |
| `action_id` | `ACTION_666GI` |
| `governance_basis` | The product owner authorized the next ten normal, bounded master-roadmap actions under the existing autonomous delivery controls. |
| `selected_outcome` | A finite, provider-free advisory presentation-key projection for the seven already-fixed exit-explanation tuples. |
| `product_value` | A later admitted read-only presentation can localize, announce and test a stable semantic key instead of matching Swedish prose. |
| `authority_boundary` | Selection only; no implementation, caller, runtime wiring or production effect. |
| `input_boundary` | Only the existing closed `decision_status`, `decision_reason` and `decision_priority` tuple may be considered by the following action. |
| `output_boundary` | One fixed non-user, non-position, non-recommendation presentation key for each of the seven known tuples. |
| `required_evidence` | Protected-main identity, exact-main six-shard CI, matched candidate/main provenance and static source assertions. |
| `next_action` | `ACTION_666GJ` may implement only the selected pure projection and its focused provider-free coverage. |

## Candidate evaluation

| Candidate | Decision | Reason |
| --- | --- | --- |
| Wire the existing explanation into a route, component or API | Rejected | Route/UI and authenticated read boundaries remain separately blocked. |
| Import or invoke the canonical exit evaluator | Rejected | A pure explanation/key projection cannot gain evaluator, data or decision authority. |
| Change CI, required checks, branch protection or Netlify | Rejected | The known Draft shape and Ready/exact-main six-shard controls remain unchanged. |
| Add another review of the closed explanation-table workstream | Rejected | The prior cap is complete; a successor needs a separately declared product outcome. |
| Select a finite advisory presentation-key projection | Selected | It is deterministic, local and later useful for accessible read-only presentation without interpreting caller text. |

## Required containment

`ACTION_666GJ` may add a standalone source-only projection for exactly the
seven tuples already accepted by Action 666GA. Its keys must be fixed source
literals and cannot contain a price, quantity, account, position,
recommendation, timestamp, credential, policy, provider, broker or user
identity. It must not import or invoke the evaluator, read environment or
network state, mutate state, expose a route or assert execution authority.

This selection reopens no runtime capability. It permits only the explicitly
bounded source-only successor described above; any wider capability is a
separate redesign-or-stop decision.
